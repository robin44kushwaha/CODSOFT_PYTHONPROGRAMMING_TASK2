Features:
- **Basic Operations:** Addition, Subtraction, Multiplication, and Division.
- **Chained Calculations:** Continue calculating using the result of your previous operation.
- **Robust Error Handling:** Built-in safeguards against division by zero and invalid user inputs (non-numeric values or unsupported operator symbols).
- **Restart & Exit Options:** Easily clear the memory to start a new calculation or exit gracefully.
